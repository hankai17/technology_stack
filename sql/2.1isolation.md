普通 SELECT
    → 一致性读 → Read View

UPDATE / DELETE / SELECT ... FOR UPDATE
    → 当前读 → 当前最新版本 + 锁

对于可重复读，查询只承认在事务启动前(该事务的 Read View 建立时)就已经提交完成的数据；
    这个事务的 Read View 建立时已经提交的数据，我能看到；之后其他事务再提交的数据，我的普通一致性读看不到。
对于读提交，查询只承认在语句启动前(select语句开始)就已经提交完成的数据；
    每一条 SELECT 开始的时候，都重新建立/获取一个 Read View；在这个时刻已经提交的数据，我能看到。

当前读（current read）”的核心特征，是读取数据库中“当前最新版本”的数据，而不是按照 Read View 去找历史版本；
它通常伴随着锁，因此最典型地出现在 UPDATE、DELETE 和 SELECT ... FOR UPDATE 等语句中。
