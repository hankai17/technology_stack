select city,name,age from t where city='杭州' order by name limit 1000  ;

CREATE TABLE `t` (
  `id` int(11) NOT NULL,
  `city` varchar(16) NOT NULL,
  `name` varchar(16) NOT NULL,
  `age` int(11) NOT NULL,
  `addr` varchar(128) DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `city` (`city`)               为避免全表扫描，我们需要在 city 字段加上索引。
) ENGINE=InnoDB;

InnoDB 的普通二级索引采用 B+ 树组织索引记录：
- (Beijing, 1) 是一条记录 单独存放一个叶子节点。
- (Beijing, 3) 是另一条记录 单独存放一个叶子节点。
- (Beijing, 5) 又是一条记录 单独存放一个叶子节点。
这些记录按照 (city, id) 的顺序排列。city 相同时，再按主键 id 排序

------------------------------------------------

全字段排序： 排序前把结果需要的字段都取齐，排序后直接返回。
rowid 排序： 排序前只取排序字段和主键，先筛出前 1000 个结果，再回表补齐其他字段。

也就是说 让排序尽可能的在内存中进行 而非借助磁盘交换空间 
------------------------------------------------
可以在这个市民表上创建一个 city 和 name 的联合索引 联合索引本身有序
alter table t add index city_user(city, name);      # 能够保证从 city 这个索引上取出来的行，天然就是按照 name 递增排序


可以创建一个 city、name 和 age 的联合索引 覆盖索引 直接获取有序的name age
alter table t add index city_user_age(city, name, age);
